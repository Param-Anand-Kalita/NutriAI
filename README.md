# NutriAI 🥗

**NutriAI** is a premium, AI-powered nutritional analysis and meal-building platform. Designed with a sleek, modern aesthetic, it helps users optimize their diet through real-time feedback, granular macro-nutrient tracking, and intelligent food substitutions.

![NutriAI Banner](https://images.unsplash.com/photo-1490645935967-10de6ba17061?q=80&w=1200&auto=format&fit=crop)

## ✨ Key Features

### 🛠️ Interactive Meal Builder
- **Dynamic Search:** Explore an extensive database of 100+ food items categorized from healthy (Fruits/Vegetables) to indulgent (Fast Food).
- **Quantity Management:** Easily adjust portion sizes with intuitive `+` and `-` controls. Identical items are automatically aggregated to keep your list clean.
- **Live Tracking:** Real-time calculation of Total Calories, Carbs, Fat, and Protein as you build your meal.

### 📊 In-Depth Nutritional Analysis
- **Macro Breakdown:** Visualize your meal's composition with a professional-grade dashboard.
- **Smart Scoring:** Receive a "Meal Score" based on the nutritional density and balance of your selections.
- **Protein Priority:** Optimized data hierarchy that places protein as the definitive metric for fitness-conscious users.

### 💡 AI-Powered "Better Alternatives"
- **Interactive Suggestions:** Get instant recommendations for healthier swaps (e.g., swapping White Bread for Whole Wheat or Soda for Green Tea).
- **One-Click Optimization:** Applying an alternative automatically replaces the item in your meal and updates your total stats instantly.

### 🖼️ High-Quality Visuals
- **Local Photo Library:** Integrated a custom library of high-resolution local images for food items to provide a premium, tactile feel.
- **Responsive Design:** A fully fluid experience across mobile, tablet, and desktop.

## 🚀 Tech Stack

- **Framework:** [React 18](https://reactjs.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** Optimized for [Vercel](https://vercel.com/)

## 🛠️ Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Param-Anand-Kalita/NutriAI.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
